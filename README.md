# 3D Physics Sandbox

A fun web game where you drop shapes, change gravity, and watch things crash.

**[Click here to play the demo right now!](https://RajanKCKC.github.io/3D-Physics)**

---

## Quick Start

To try it out, just open the link above. It works right in your browser.

Here is how you play:

* **Click** the ground to drop a shape.
* **Spacebar** drops random shapes.
* **R** restarts the game.
* **P** pauses or plays.
* **C** clears the screen.

## What You Can Do

* Drop boxes and balls, and choose how big or heavy they are.
* Change gravity to make things fall sideways or even float up.
* Make objects super bouncy or very slippery while they are falling.
* Slow down time to watch crashes in slow motion.
* Play forever without the game freezing old shapes clean themselves up.

## How To Run It On Your Computer

Want to look at the code or run it yourself?

1. Download or clone this code to your computer.
2. Run a local web server (like Live Server in VS Code).
3. Open the folder, and it will run right away! No big downloads or installs needed.

## How It Works

All the math for the falling objects happens right inside your browser. Because it doesn't wait on a server, the game runs super fast and smooth (60 frames per second). You get nice shadows and lighting, and the moment you move a slider, the game changes instantly.

## Made With

Big thanks to the tools that made this easy to build:

* **Three.js** - Draws all the 3D shapes and shadows.
* **Cannon-es** - Does the math to make things fall and crash.
* **Orbit Controls** - Lets you move the camera around.
